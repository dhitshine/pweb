# Portfolio Website

Static CV & portfolio untuk tugas Pemrograman Web (Week 2). Dibangun dengan HTML5 + CSS3.

## Struktur

- `index.html` — about me, skills, education, portfolio, contact
- `css/style.css` — CSS variables, Flexbox + Grid, responsive media queries
- `images/` — foto profil

## Fitur

- Navigasi sticky dengan anchor link
- Tata letak responsive
- Font JetBrains Mono + Merriweather via Google Fonts

## Menjalankan

Buka `index.html` langsung di browser.
