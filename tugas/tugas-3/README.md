## Deskripsi

Student Management Dashboard adalah halaman statis untuk menampilkan formulir dan data mahasiswa ITS. Halaman dibuat dengan HTML dan CSS, serta responsif untuk berbagai ukuran layar.

> Aplikasi web ini berfokus pada implementasi CSS, sehingga tombol belum berfungsi dan pengguna belum dapat menambah atau mengelola data

## Struktur Project

```text
.
├── index.html
├── style.css
└── README.md
```

## Fitur

- Form data mahasiswa: NRP, nama lengkap, program studi, dan email.
- Pilihan program studi: Teknik Informatika, Rekayasa Perangkat Lunak, dan Rekayasa Kecerdasan Artifisial.
- Tabel contoh data mahasiswa beserta NRP dan email mahasiswa ITS.
- Tampilan responsif.
- Tombol Reset Form berfungsi untuk mengosongkan isian.
- Tombol tambah, cari, edit, hapus, dan pagination hanya berupa tampilan, belum memiliki fungsi interaktif.

## Cara Menjalankan

1. Buka `index.html` langsung di browser atau
2. Jalankan server lokal dari folder project:

   ```bash
   python3 -m http.server 8000
   ```

3. Buka <http://localhost:8000/> di browser.
